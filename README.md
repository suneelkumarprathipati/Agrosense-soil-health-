# 📖 Overview

AgroSense AI is an AI-powered precision agriculture platform designed to assist farmers with intelligent crop management, disease prediction, soil analysis, irrigation recommendations, and data-driven farming decisions.

The platform combines Machine Learning, Artificial Intelligence, modern web technologies, and cloud deployment to provide a responsive agricultural decision support system.

# 🚀 Installation

## Clone Repository

```bash
git clone https://github.com/yourusername/agrosense-ai.git
```

---

## Install Frontend

```bash
npm install
```

---

## Run Frontend

```bash
npm run dev
```

---

## Backend

```bash
cd backend

pip install -r requirements.txt

python app.py
```
